# SONAX ($SONAX)

**SONAX** is the native utility token of the **SONAX AIFi ecosystem** — an Agentic Finance (AIFI) infrastructure that coordinates multiple on-chain agents for market data, quantitative strategies, risk control and verifiable execution.
